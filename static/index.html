Frequently Asked Teacher / Viva Defense Questions

Q1: Why did you choose Random Forest over a single Decision Tree or Logistic Regression?

Single Decision Trees suffer from high variance and easily overfit small datasets. Random Forest trains an ensemble of 100 decorrelated decision trees using bootstrap aggregating (bagging) and random subspace feature sampling, significantly reducing generalization error and preventing overfitting on complex NPK soil interactions.

Q2: How did you preprocess categorical features (Soil Type, Crop Type) in the Fertilizer dataset?

We utilized scikit-learn's LabelEncoder to encode categorical labels into integer representations. In tree models, label encoding effectively bifurcates categorical branch splits without expanding the sparse dimensionality of the dataset.

Q3: How did you prevent Data Leakage during feature scaling?

We strictly applied StandardScaler.fit_transform() only to the 80% training partition (X_train). The test partition and all incoming live inference inputs are transformed using scaler.transform(), ensuring test distributions are completely unseen during normalization.

Q4: What features exhibited the highest predictive importance for crop selection?

Based on the Gini feature importance chart (07_feature_importance.png), Rainfall and Humidity are the most dominant split criteria, followed by Potassium (K) and Nitrogen (N). This matches agronomic biology: precipitation and moisture govern plant survival and transpiration.

Q5: How can this system be validated in real field conditions before large-scale adoption?

Using Fisher's Principles of Agronomic Experimentation, we conduct a Randomized Complete Block Design (RCBD) field trial. We block across natural soil fertility gradients to isolate environmental noise, randomize treatments against conventional farmer practice across at least 5 independent plots per condition, and measure final crop yield.
