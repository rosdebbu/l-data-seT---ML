TOPIC 1

Machine Learning: What & Why?

What is ML? Teaching computers to learn patterns from data and make predictions without writing explicit rules.

Normal ProgrammingMachine Learning
You write IF-ELSE rulesComputer discovers rules from data
Input + Rules = OutputInput + Output = Rules (learned)
Breaks when new situations ariseAdapts to new patterns automatically

Why do we need ML?

  • Too many variables for manual rules (22 crops, 7 soil features)
  • Data is growing faster than humans can analyze
  • Patterns too complex for human observation (detecting cancer from X-rays)

TOPIC 3

Training vs Testing

Training (80% data)

Feeding data WITH known answers to the model. Model adjusts its weights to learn patterns. Like studying from a textbook.

Testing (20% data)

Evaluating model on NEW unseen data. Tests if the model actually learned. Like taking the real exam.

Key Rule: NEVER test on the same data you trained on — that's like memorizing exam answers, not real learning!

TOPIC 5

Cross-Validation

Problem: A single 80/20 split gives different accuracy each time depending on random luck.

Solution: K-Fold Cross-Validation — split data into K equal parts, rotate testing across all parts.

Round 1: [TEST ] [TRAIN] [TRAIN] [TRAIN] [TRAIN] → 92% Round 2: [TRAIN] [TEST ] [TRAIN] [TRAIN] [TRAIN] → 88% Round 3: [TRAIN] [TRAIN] [TEST ] [TRAIN] [TRAIN] → 95% Round 4: [TRAIN] [TRAIN] [TRAIN] [TEST ] [TRAIN] → 90% Round 5: [TRAIN] [TRAIN] [TRAIN] [TRAIN] [TEST ] → 93% Final Score = Average = 91.6% (reliable!)
Key: Every data point gets tested exactly once. No lucky or unlucky splits.
TOPIC 6

Types of Learning

Supervised Learning

Data has labels (known answers). Model learns: input → output mapping.

Example: Given soil data → predict crop name. Algorithms: Random Forest, KNN, Linear Regression.

Unsupervised Learning

Data has NO labels. Model finds hidden patterns / groupings on its own.

Example: Grouping farmers by similar soil conditions. Algorithms: K-Means, PCA.

Semi-Supervised Learning

Mix of labeled + unlabeled data. Small portion has labels, large portion doesn't.

Example: 100 soil samples but only 10 have crop labels.

SupervisedUnsupervisedSemi-Supervised
Labels?All labeledNo labelsSome labeled
GoalPredict outputFind hidden patternsPredict using limited labels
ExampleCrop RecommendationSoil clusteringPartially labeled data
TOPIC 7

Curse of Dimensionality

Dimensions = Number of features (columns). Our crop dataset has 7 features = 7 dimensions.

The Curse: As features increase, data becomes sparse (spread too thin). Distance between points becomes meaningless.

Simple analogy:
• Finding your friend in a line (1D) → Easy, look left/right
• Finding your friend in a room (2D) → Harder, scan the floor
• Finding your friend in a building (3D) → Very hard
• Finding your friend in 100 dimensions → Nearly impossible!

How to Fix It

  • Feature Selection — Remove useless features
  • PCA — Compress 100 features into 10 important ones
  • More Data — Collect more samples to fill the space
TOPIC 8

Overfitting & Underfitting

THE MOST ASKED EXAM TOPIC. Memorize this well!

Underfitting (Too Simple)

Model CANNOT learn patterns. Bad on training AND test data.

Like a student who didn't study — fails everything.

Fix: More complex model, more features.

Overfitting (Too Complex)

Model MEMORIZES noise. Great on training, BAD on test.

Like memorizing exact textbook answers — fails new questions.

Fix: Regularization, more data, simpler model.

Training AccuracyTest AccuracyProblem
UnderfittingLOWLOWToo simple
Good FitHIGHHIGHPerfect!
OverfittingVERY HIGHLOWMemorized noise

TOPIC 10

Bias & Variance Tradeoff

BiasVariance
Caused byModel too SIMPLEModel too COMPLEX
Leads toUnderfittingOverfitting
AnalogyConsistently wrong (always misses target the same way)Scattered everywhere (no consistency)
Total Error = Bias² + Variance + Irreducible Noise
The tradeoff: Decrease Bias → Variance increases. Decrease Variance → Bias increases. You must find the sweet spot in the middle!
TOPIC 11

Regularization

Adds a penalty for large weights to prevent overfitting.

Ridge (L2)Lasso (L1)
Penaltyλ × sum(weights²)λ × sum(|weights|)
EffectShrinks ALL weights toward 0Shrinks SOME weights to EXACTLY 0
Feature Selection?No (keeps all features)Yes (drops useless features)
Lambda (λ):
• λ = 0 → No regularization (normal model)
• λ = small → Light regularization
• λ = large → Heavy regularization (all weights → 0 = underfitting)

TOPIC 14

Error and Noise

Noise = Random meaningless variations (faulty sensors, typos). Cannot be fixed — it is irreducible.

Total Error = Bias² + Variance + Irreducible Noise
Error ComponentCaused ByFixable?
Bias²Model too simpleYes — use complex model
VarianceModel too complexYes — regularization, more data
NoiseRandom junk in dataNo — irreducible

TOPIC 16

Linear Algebra for Machine Learning

Why? ALL ML computations use matrices and vectors.

Key Concepts

ConceptWhat it IsExample
VectorA single data sample (list of numbers)[90, 42, 43, 20, 82, 6.5, 202]
MatrixEntire dataset (table of numbers)200 rows × 7 columns
Dot ProductMultiply elements & sumUsed for predictions (X · W)
TransposeFlip rows ↔ columnsUsed in matrix algebra formulas
Inverse"Undo" a matrixSolving regression weights
Prediction = X × W + b

X = feature matrix (200×7) • W = weight vector (7×1) • b = bias/intercept
